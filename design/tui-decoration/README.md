# HAJI 首屏装饰提案

双击本目录的 `index.html` 即可打开交互原型，无需安装依赖或启动服务。所有数据都是示例，不访问真实会话，不调用模型。本次仅新增设计文件，没有把装饰接入正式 TUI。

## 三个方向

| 方向 | 装饰语言 | 气质与取舍 | 建议 |
| --- | --- | --- | --- |
| 01 纸上手记 | 纸白与橄榄绿、编号页签、细章节线、折页字符画、浅色选择条 | 延续当前 paper 主题，装饰轻；浅色细线的实际对比度需要随终端背景调节 | 推荐作为默认首屏 |
| 02 星轨工作台 | 淡紫、点阵与轨道字符、开放章节线、观测记录式侧栏 | 品牌辨识度更强、轻松；小窗口会隐藏星图 | 适合作为另一套主题，或只借用字符星图 |
| 03 琥珀仪表台 | 深色琥珀、框线、三位编号、状态刻度与信号字符画 | 终端感最强、信息边界清晰；框线占行数更多，矮窗口切回章节线 | 适合偏爱深色控制台的用户 |

三套方案的信息量相同，默认截图分别为纸白、浅紫、深琥珀。页面可以切换每套方案的深浅色，便于在同样外观下比较。Logo 为原型重绘的紧凑三行字符标识；落地时也可保留原 Logo，只调整占用行数。

## 可以体验的交互

- 点击前三个入口：填入草稿，保留手动发送的机会。
- 空输入时按 Tab / Shift+Tab 或上下方向键：循环选择六个入口；Enter 打开当前入口。
- 输入草稿后按 Enter：显示对话演示，欢迎区与装饰图案收起。
- 点击最近会话：显示对应的恢复演示。
- Esc 或「回到首屏」：重置演示。
- 选择 140×36、104×30、76×30、104×24：比较窗口大小；76 列隐藏侧栏并保留底部上下文与费用摘要，24 行缩小 Logo 并减少装饰。
- 「切换深色」「ASCII 降级」：比较终端能力降级。

## 实现边界

终端区域采用固定字格，仅使用字符、前景色与整格背景色，没有圆角 CSS、投影、图片、模糊或持续动画。外部浏览器控制条和说明区属于原型查看器，不进入 TUI。正式落地时复用现有颜色降级与宽度裁切工具，悬停只换色，装饰不进入可点击区域。字符插画和页签优先在首屏呈现，进入对话后收起。

方案尚未接入真实 TerminalUI；浏览器字体与 Windows Terminal 的字体栅格可能不同。实际实现还需验证真实终端的字宽、无色模式和背景透传。ASCII 开关只降级装饰字符，保留中文界面文案。

## 验证

在仓库根目录运行 `node design/tui-decoration/verify.mjs`。脚本通过本机 Chrome / Edge 的 CDP 验证原型，也会重新生成五张截图；可通过 `CHROME_PATH` 指定浏览器路径。脚本的临时浏览器配置位于 `.tmp/`，不更改日常浏览器配置。

覆盖三方案 × 两种明暗 × 四种尺寸 × 两种字符模式，共 **48 种布局组合**；检查字格宽度预算、入口命中范围、输入位置、窄屏关键指标和 ASCII 降级。通过实际浏览器键盘及鼠标事件核对草稿、发送、恢复、重置；另检查手机宽度下页面外层不溢出。截图人工核对装饰、文本和输入框的相对位置。
