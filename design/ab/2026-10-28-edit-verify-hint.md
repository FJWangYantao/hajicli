# edit_verify_hint：用静态提示代替逐次验证通知

日期：2026-10-28
数据：`data/2026-10-28-edit-verify-hint.json`（3 任务 × 2 arm × 3 轮 = 18 次运行）
脚本：`write-bench/run.sh`（`ARMS="baseline hint"`）

## 假设

上一轮把「验证通过」的逐次回注去掉了（`2026-10-27-verify-notice.md`），代价是模型
**永远不知道验证跑过了**，所以每次改动后仍自己跑一遍 `tsc`（两臂都是 1 次/会话）。

这次换静态提示：在 system prompt 里固定写一段「编辑后系统会自动跑类型检查（`npx tsc -b`），
不要为了确认自己的改动重复运行 tsc/typecheck/构建」，看能不能把那次自检省掉。

机制清楚、可测：主指标不是墙钟，而是**模型自己跑了几次 tsc**。

## 方法

- 两臂**同一份构建**，只切实验开关：`HAJI_EXPERIMENTS=edit_verify_hint=baseline|hint`。
- 提示只在真的会跑验证时注入（探测到检查命令、且不是 haji 自身仓库）。
- 已从 trace 的 `llm_call` messages 核实注入生效：**9/9 hint 会话的 system prompt 含该段，
  9/9 baseline 不含**。
- 任务：1（加函数 + 测试）、2（跨文件重命名，强制 edit）、3（修边界 + 回归测试），各 3 轮。
- tsc 计数口径：`tscForTest` = 该 `tsc`/构建命令之后（含同一条 bash）还跑过测试，即
  **为跑测试刷新 `dist`**；`tscStandalone` = 之后没跑测试的**纯类型检查**。

## 结果

正确性：**18/18 全对**（`tsc -b` 通过、测试通过、重命名无残留）。

| 指标 | baseline | hint | 变化 |
| --- | ---: | ---: | ---: |
| 墙钟 / 次 | 47.9s | 59.2s | +23.7% |
| 请求 / 次 | 12.4 | 13.3 | +7.1% |
| prompt token / 次 | 127,328 | 139,585 | +9.6% |
| 未命中 token / 次 | 12,497 | 15,467 | +23.8% |
| completion token / 次 | 2,436 | 2,697 | +10.7% |
| **tsc / 构建命令（9 次合计）** | **7** | **6** | **−1** |
| ├ 为跑测试刷新 dist | 5 | 5 | 0 |
| └ 纯类型检查 | 2 | 1 | −1 |
| 测试命令 | 9 | 8 | −1 |

逐轮（墙钟秒）：hint 更快 6 对、更慢 3 对（27→75、26→57、66→116 是三个离群），
中位数 38s → 56.5s。均值被三个离群拉高，**墙钟不归因**。

## 关键发现

1. **机制没有生效**：18 次运行里 tsc/构建命令只从 7 次降到 6 次，纯类型检查 2 次 → 1 次。
   模型读到了这段提示（trace 里有），但照样自己跑 `tsc -b`。
2. **大部分 tsc 根本省不掉**：7 次里有 5 次是**为了跑测试刷新 `dist`**——本仓库测试
   `import ... from "../../plugins/dist/xxx.js"`，不先 `tsc -b` 测试拿到的就是旧代码。
   这类调用是任务的一部分，提示里也明确豁免了「任务要求跑测试」，所以上限本来就只有
   1–2 次/会话。
3. **提示只有成本**：每轮多约 250 token 的 system 段；请求 +7%、prompt token +9.6%，
   墙钟差异全在噪声里。
4. 这是第二次「告诉模型验证已经做过了」失败：逐次通知（verify-notice）和静态提示
   （本轮）都没能改变它的自检习惯。模型的 `tsc` 主要由**需要新 `dist`** 驱动，
   而不是「不信任 harness」。

## 结论

**否定，默认保持 `baseline`**。代码保留在 `EditVerifyPromptPart` + `edit_verify_hint`
开关里，供后续更窄的变体实验（例如只在「没有测试要求」的任务里注入，或直接解决
测试依赖 `dist` 的问题）。

要真正消掉那次自检，方向不在提示词：
- 让测试从 `src` 导入（或加 `tsx`/`--experimental-strip-types` 类路径），`dist` 不再是前置条件；
- 或让验证钩子把「已通过」写进工具回执本身（一次调用内可见），而不是额外一条 system 消息。

## 复现

```bash
ROUNDS="1 2 3" TASKS="1 2 3" ARMS="baseline hint" bash design/ab/write-bench/run.sh
```
